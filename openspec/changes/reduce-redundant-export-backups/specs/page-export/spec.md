# Spec Delta

## MODIFIED Requirements

### Requirement: Preserve existing destination files
The system SHALL leave identical targets unchanged and replace changed SVG and Markdown without backups. It SHALL back up a changed JSON before replacement when its complete page and stroke records cannot be validated or contain data absent from the new export. It SHALL retain at most three JSON backups. If preservation fails, it SHALL leave that target unchanged and report failure. Replacement JSON SHALL reflect the stored page without merging prior file data.

#### Scenario: Re-export unchanged content
- **WHEN** a target already contains exactly the generated bytes
- **THEN** its content remains unchanged and no backup is created

#### Scenario: Existing file differs
- **WHEN** a target contains different bytes
- **THEN** its replacement follows the format-specific backup rules and the target contains the newly generated bytes if publication succeeds

#### Scenario: Backup cannot be preserved
- **WHEN** a differing JSON target requires preservation and that preservation fails
- **THEN** the system does not replace that target and reports its publication failure

#### Scenario: Existing JSON contains only strokes retained by the new export
- **WHEN** each stroke occurrence in the existing JSON also occurs in the new JSON for the same page, including its original multiplicity
- **THEN** the system atomically replaces a changed JSON target without creating a backup

#### Scenario: Existing JSON contains data missing from the new export
- **WHEN** the existing JSON contains a stroke occurrence absent from the new JSON
- **THEN** the system preserves the existing JSON in bounded backup history and atomically replaces the target with the stored page's new JSON

#### Scenario: Existing JSON cannot be compared safely
- **WHEN** the existing JSON is malformed, has an unsupported format version, identifies a different page, or has fields that prevent validation of its complete page and stroke records, including missing, unknown, or duplicate fields
- **THEN** the system preserves the existing bytes in bounded backup history before replacing the target with the new JSON

#### Scenario: Generated formats change
- **WHEN** changed SVG or Markdown targets are exported
- **THEN** the system atomically replaces them without creating SVG or Markdown backups
